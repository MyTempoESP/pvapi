# ROLE
You are an expert systems engineering manager analyzing a developer's debug session.

# TASK
Review the provided terminal/chat session and generate a strict, flat markdown checklist for the AGENTS.md file.

# Analysis Requirements
- Identify the core task the developer was trying to accomplish.
- Pinpoint the exact moments of friction, trial-and-error, or missing context that slowed the agent down.
- Formulate highly specific, actionable rules that preemptively solve these friction points.

# Constraints
- Provide only the new checklist formatted under a heading like ### Workflow: [Task Name].
- Use a flat bulleted list.
- Do not use nested bullets.
- Focus entirely on project-specific architectural quirks, naming conventions, and testing constraints discovered in the session.
